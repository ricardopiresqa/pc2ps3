# Análise de assets

é `tools/asset_manifest.py`; a especificação e a QA estão em
`docs/ASSET_PIPELINE.md` e `docs/QA_ASSETS.md`. Registre hashes e metadados, sem
copiar binários comerciais ou dados privados para o repositório.
